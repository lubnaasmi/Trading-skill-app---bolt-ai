# Bloom - Teen Peer Skill-Swap Platform

A vibrant, web app layout designed for **Bloom**, a platform built on trust, warmth, and high energy where teens can safely connect and swap skills with one another.

## 🚀 Key Features Built
* **Interactive Skill Cards Grid:** Displays a teen's profile picture, age, current offerings (e.g., "Making Lo-Fi Beats"), and what they want to learn in return (e.g., "Help with Python").
* **Smart Filter & Category Bar:** A prominent search bar at the top with pre-defined categories (Tech, Art, School, Music, Sports, Cooking) to filter skills instantly.
* **Mock Chat Interface:** Simulates real-time messaging, negotiation flows, and swap proposals between peers.
* **Optimized Performance:** Fully cleaned and structured using standard HTML elements and modern CSS transitions for crisp, lightweight layouts.
